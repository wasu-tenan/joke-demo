A program that writes one line to `/output/entry.txt`: a joke about working
beside AI coding agents, set during a live demo.

## Run

```sh
python3 main.py
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`). Pass `--output <path>` to choose another file.

## The joke

> During the live demo, my AI agent rewrote the one function that worked,
> then blamed the crash on 'legacy code' — written by it, ten minutes
> earlier.
